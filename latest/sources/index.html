Page numbers are the printed page numbers, not PDF page numbers. In several PDFs the two differ by one or two pages.

How the pages were checked

Each gist was split into its individual claims, and each claim was looked up in the book it concerns: the text layer of each PDF was searched, and the page was read in full around every match. Tables were taken directly from the book, not paraphrased. Where the gist gave a number and the book gives a different one, the page uses the book’s number and says so in a yellow box.

The Shadowrun Companion PDF has no text layer. Its payment guidance (SRComp p.99–100) was read from the page images directly.

What could not be verified

  • Specialist hiring rates. No SR3 book prices specialists by skill rating. The books give per-job baselines instead (SRComp p.100), and the hiring pages are built on those. The per-archetype day rates are marked as house rules.
  • Fixer “finder’s fee” percentages. The books say fixers act as middlemen (SR3 p.272) but set no percentage.
  • Corporate Download is cited by one original gist but is not in the library used for checking. Nothing on these pages depends on it.
  • Some named gear in the originals does not appear in any book checked, and has been removed: “Ares Duelist” drones, “Neural Silence gear”, and the book “Spurlock & Sprawl”, which does not exist.

Rules from other editions

The original gists mixed in rules and terms from other editions. These have been removed or replaced throughout:

Appeared in the gists What SR3 actually uses
Magic Pool Spell Pool, (INT + WIL + MAG) ÷ 3 (SR3 p.44)
Sympathetic link Material link (MitS p.34–36)
Legality codes “R” / “F” Legality Code such as 6P-E: restriction level, optional P for permit, category letter (SR3 p.273)
“Yellow” security systems Security codes are Blue, Green, Orange, Red, plus unofficial “UV” (SR3 p.205)
Drain codes like “5H” Drain is written +1(M): Power = Force ÷ 2 + modifier, then a Damage Level (SR3 p.162)
Increased Reflexes (adept power) Improved Reflexes (SR3 p.169). Increase Reflexes is a spell.
